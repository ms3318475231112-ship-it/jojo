# تسعير الدهان – قسم الزخرفة

برنامج لحساب خامات الدهان والأجور وقيمة البند. بيشتغل على الموبايل كأنه تطبيق، وبيفتح من غير إنترنت بعد أول مرة.

## الملفات

| الملف | وظيفته |
|---|---|
| `index.html` | البرنامج نفسه، ومعاه الشاشة الافتتاحية |
| `manifest.webmanifest` | اسم التطبيق وأيقوناته وألوانه |
| `sw.js` | تشغيل البرنامج من غير إنترنت |
| `splash-icon.webp` | صورة الشاشة الافتتاحية |
| `icons/` | الأيقونات بكل المقاسات (أندرويد، آيفون، المتصفح) |
| `screenshots/` | صور للبرنامج بتظهر في شاشة التثبيت |
| `.nojekyll` | ملف فاضي بيخلي GitHub Pages يعرض الملفات زي ما هي |

## ١. الرفع على GitHub

1. ادخل على github.com واعمل حساب لو مش عندك.
2. اضغط **New repository**، وسمّيه مثلاً `paint-pricing`، واختار **Public**، وبعدين **Create repository**.
3. اضغط **uploading an existing file**، واسحب كل الملفات والفولدرات اللي في الفولدر ده جوه الصفحة.
   - لازم `index.html` يكون في أول الـ repository، مش جوه فولدر.
   - ملف `.nojekyll` ممكن ميظهرش عندك على الكمبيوتر لأنه ملف مخفي. لو مترفعش، البرنامج هيشتغل عادي برضه.
4. اضغط **Commit changes**.

## ٢. تشغيل الموقع (GitHub Pages)

1. من الـ repository ادخل **Settings** ← **Pages**.
2. في **Source** اختار **Deploy from a branch**، وبعدين **main** و **/(root)**، واضغط **Save**.
3. استنى دقيقة أو اتنين. الرابط هيبقى بالشكل ده:
   `https://اسم-المستخدم.github.io/paint-pricing/`

## ٣. تثبيته على الموبايل

- **أندرويد (Chrome):** افتح الرابط، ومن قايمة ⋮ اختار **تثبيت التطبيق** أو **إضافة إلى الشاشة الرئيسية**.
- **آيفون (Safari):** افتح الرابط، واضغط زرار المشاركة، واختار **إضافة إلى الشاشة الرئيسية**.

## ٤. عمل ملف APK لأندرويد (اختياري)

1. ادخل على **pwabuilder.com**.
2. حط رابط GitHub Pages واضغط **Start**.
3. اختار **Package for stores** ← **Android** ← **Generate**.
4. هينزل ملف مضغوط فيه ملف APK تقدر تثبّته على أي موبايل أندرويد، وفيه كمان ملف AAB لو حبيت ترفعه على Google Play.

## لما تعدّل أي حاجة

ارفع الملف الجديد مكان القديم على GitHub، وبعدين افتح `sw.js` وغيّر السطر ده:

```js
const VERSION = 'v1';
```

لـ `'v2'`، وبعدها `'v3'`، وهكذا مع كل تعديل. ده بيخلي الموبايلات تحمّل النسخة الجديدة بدل النسخة المحفوظة عندها.
